# Controle Financeiro e Motorista

Projeto estático com dois controles em uma única tela:

- Controle financeiro simples para entradas, gastos e saldo.
- Menu lateral para criar, abrir e editar listas financeiras por nome e data.
- Controle semanal de motorista com horas, quilometragem, combustível, manutenção e lucro líquido.

Os dados são salvos no `localStorage` do navegador.

## Como usar

Abra o arquivo `index.html` no navegador.
